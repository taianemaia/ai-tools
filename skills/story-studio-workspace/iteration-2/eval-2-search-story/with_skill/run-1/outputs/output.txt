INPUT:
As a shopper I want to search for products so that I can find things to buy

--------------------------------------------------------------------------------

[STORY WRITER - turn 1]

STORY:

**Story:** As a shopper, I want to search for products by keyword so that I can quickly find items I am interested in purchasing.

**Acceptance Criteria:**
- The search bar is visible and accessible from the site header on all pages.
- Submitting a keyword returns a results page listing products whose name, description, or category match the search term.
- Each result displays at minimum the product name, thumbnail image, and price.
- When no products match the search term, the page displays a "no results found" message along with the term that was searched.
- Search results are returned within 3 seconds under normal load conditions.
- The shopper can navigate to a product detail page by clicking any result.

**INVEST Note:** The story is Independent (can be built without other stories), Negotiable (scope of matching logic is flexible), Valuable (directly supports purchase intent), Estimable (standard search pattern), and Testable (each criterion is verifiable); it is reasonably Small for a sprint.

**Story Points:** 5 — Involves a search UI component, backend query integration, results page layout, and empty-state handling; moderate complexity.

**Open Questions:**
- Search matching logic — assumed to match against product name, description, and category; the exact fields and whether fuzzy/partial matching is supported have not been confirmed.
- Sorting and filtering of results — not mentioned in the input; assumed out of scope for this story.
- Authentication — assumed search is available to unauthenticated shoppers; confirm if logged-in-only behavior is required.
