User Story: 404 Handling for PDP Routes

Title:
As a shopper, I want to see a proper 404 page when I navigate to an invalid or unavailable product URL, so that I have a clear and helpful experience instead of a broken page.

Description:
When a user navigates to a Product Detail Page (PDP) route, the system should validate the product and return a 404 response if the product is not accessible. The 404 rules should align with AEM's behavior to ensure consistency across the platform.

Acceptance Criteria:
- Given a user navigates to a PDP route with an invalid SKU, then they should see a 404 page.
- Given a user navigates to a PDP route for a product that is unpublished, then they should see a 404 page.
- Given a user navigates to a PDP route for a product that is out-of-market for their locale, then they should see a 404 page.
- Given a user navigates to a PDP route for a valid, published, in-market product, then they should see the product detail page as expected.
- The 404 behavior should match the rules applied by AEM for consistency.

Notes:
- AEM 404 rules: a product is 404'd if the SKU is invalid, unpublished, or out-of-market for the user's locale.
- Locale-based out-of-market checks must account for the user's current locale context.
